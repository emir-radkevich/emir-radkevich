## About me

Computational Scientist at the Icahn School of Medicine at Mount Sinai, building Python pipelines for spatial and single-cell biology. I work across 10x Visium/Xenium, scRNA-seq, and high-plex imaging (Orion MxIF), designing tools like `visium_analysis` — used directly in a 2026 Science publication — and **PathoLytica**, an HPC-scaled imaging pipeline processing 1TB+ tissue image batches (institutional, not public), used in a JCI 2025 paper. Co-author on 9+ papers in Science, Nature, and Immunity. 

**Stack**: Python (scanpy, lazyslide, SpatialData, scikit-learn), R (Seurat), Nextflow, Docker, LSF/Slurm.
